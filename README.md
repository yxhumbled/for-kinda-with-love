# a little something for kinda

## make it yours

1. Open `script.js` and edit the `MESSAGES` array to personalize the heart notes and both long messages
2. In `index.html` find the photo placeholder and replace it with a photo using a relative path such as `images/us.jpg`
3. Put the photo in an `images` folder in the repository root
4. Add your song as `song.mp3` in the repository root so the music button can play it

## publish on github pages

1. Create a GitHub repository for the site
2. Add `index.html` `style.css` `script.js` and your optional photo folder to the repository root
3. Commit and push the files to the `main` branch
4. Open the repository on GitHub and select **settings** then **pages**
5. Under **build and deployment** choose **deploy from a branch**
6. Select the `main` branch and the `/ (root)` folder then save
7. Wait for GitHub Pages to finish publishing and open the site link shown in the Pages settings

The site has no build step and uses relative paths so it works from a repository page URL
